# Small language model from scratch 🚧

Decoder-only transformer trained on [TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories), written from scratch to understand attention, tokenization and training dynamics.

- `TransformerConfig.py`: hyperparameters and paths
- `TransformerData.py`: dataset loading and tokenization
- `TransformerModel.py`: model architecture
- `TransformerMain.py`: training entry point

Work in progress.
