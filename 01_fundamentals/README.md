# Fundamentals

Course exercises and first architectures, kept as a learning log.

- `001_ImageClassifier.py`: image classifier from the fast.ai course (lesson 1), with its Gradio app
- `003_PyTorchRegression.py`: linear regression written in plain PyTorch
- `004_NumberMNIST_MLP.py`: MLP on MNIST (920 kB)
- `005_NumberMNIST_CNN.py`: 2×(Conv-Pool) CNN on MNIST (1.6 MB), deployed on [HF Space](https://huggingface.co/spaces/CptDenev/MNIST_Digit_CNN)

MNIST is downloaded automatically into `dataset/mnist` on first run.
